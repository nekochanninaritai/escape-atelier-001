# Escape Atelier #001 Image Prompts

## Common Art Direction

High-quality polished digital illustration for a smartphone portrait static escape game. The room is an antique Western mansion music room at sunset: ivory walls, dark walnut wood, antique gold brass, deep moss green curtains, dark navy accents, and muted sunset orange light. The mood is quiet, warm, elegant, slightly mysterious, and never horror. Avoid people, human shadows, ghosts, blood, modern electronics, logos, watermarks, readable generated text, extra doors, and inconsistent furniture.

All readable puzzle information is implemented in React/CSS/SVG-like procedural assets, not trusted to generated imagery.

## Procedural Transparent WebP Assets

These are generated by `scripts/prepare-assets.mjs` with `sharp` from deterministic SVG source so puzzle information stays exact.

- `item-sheet-piece-01.webp`, `item-sheet-piece-02.webp`, `item-sheet-piece-03.webp`: inventory sheet fragments
- `item-winding-key.webp`: music-box winding key
- `item-completed-sheet.webp`: completed sheet music with C-E-G-E-D note pattern
- `item-door-key.webp`: old door key
- `puzzle-sheet-piece-01.webp`, `puzzle-sheet-piece-02.webp`, `puzzle-sheet-piece-03.webp`: sheet sorting puzzle pieces
- `puzzle-sheet-incomplete.webp`: incomplete sheet
- `puzzle-sheet-complete.webp`: completed sheet
- `puzzle-clock-face.webp`: clock face ornament with controlled music symbols
- `puzzle-music-box-clue.webp`: brass clue plate background; clue text is overlaid in React

## Conversion

Run this after generating or replacing source images:

```bash
node scripts/prepare-assets.mjs
```

The script converts the latest generated background PNGs from Codex image generation into optimized WebP scene assets and regenerates procedural transparent WebP item/puzzle assets.
